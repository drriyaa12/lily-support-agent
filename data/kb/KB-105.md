On paid plans, single files up to 250 MB can be uploaded in the browser or the desktop app. On the Free plan, the limit is 50 MB.

## Steps
1. **Check the file against the size limit.** Paid plans accept files up to 250 MB; the Free plan accepts files up to 50 MB.
2. **Check the workspace storage quota.** Settings → Usage shows how much storage is left. Uploads fail when the workspace is full.
3. **Upload large files from the desktop app.** The desktop app resumes interrupted uploads; browser uploads restart from zero.

## When to escalate
If a file within the limit still fails after these steps, escalate to Technical Support with the file type, size and any error code shown.
