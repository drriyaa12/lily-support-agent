Use this guide when the Quillstack desktop app closes immediately or shows a crash message when it starts. Crash fixes depend on the operating system and the app version (shown in Help → About, or in the installer file name), so confirm both first.

## Steps
1. **Update to the latest version.** Versions before 4.6.0 have a known start-up crash that updating fixes. Download the latest installer from quillstack.example/download.
2. **Restart the computer.** This clears locked files left behind by an earlier crash.
3. **Reset the local cache.** Hold Shift while opening the app to start in safe mode, then choose Reset local cache.
4. **Reinstall the app.** Uninstall Quillstack, then install the latest version again.

## When to escalate
If the app still crashes after all steps, escalate to Technical Support with the crash report (macOS: Console → Crash Reports; Windows: the logs folder under %LOCALAPPDATA%\Quillstack).
