Quillstack sends webhook events with a signature header and expects a 2xx response within 10 seconds. After 20 failed deliveries in a row, the webhook is disabled automatically. Workspaces often have several webhooks, so ask for the webhook ID (it starts with wh_ and is shown in Developer settings → Webhooks) before troubleshooting.

## Steps
1. **Check the endpoint response.** The endpoint must answer with a 2xx status code within 10 seconds. Redirects count as failures.
2. **Verify the signing secret.** Make sure the endpoint validates signatures with the current secret from Developer settings → Webhooks.
3. **Re-enable the webhook.** If the webhook shows "Disabled", choose "Enable". Failed events from the last 72 hours are retried.

## When to escalate
If deliveries keep failing after these steps, escalate to Technical Support with the webhook ID and the time of a failed delivery.
