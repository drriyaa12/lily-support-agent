Use this guide when edits made in the Quillstack desktop app do not appear on other devices or for teammates, or the app shows "Syncing…" for a long time. The cache location differs between Windows and macOS, so confirm the operating system first.

## Steps
1. **Update to the latest version.** Choose Help → Check for updates and restart the app after installing.
2. **Sign out and back in.** This refreshes the sync session without touching local files.
3. **Reset the local cache.** Choose Settings → Advanced → Reset local cache. Files stay safe in the cloud, and the app downloads them again.
4. **Reinstall the app.** Uninstall Quillstack, download the latest installer from quillstack.example/download, and install it again.

## When to escalate
If changes still do not sync after all four steps, escalate to Technical Support and ask the customer to attach the sync log (Help → Export sync log).
